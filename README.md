# Ironvale Fitness Club

A real-time 3D pixel-art gym simulation, built by **Claude Opus 5.5** on claude.ai from a single build prompt.

**▶ Try it:** https://neural-nonsense-lab.github.io/ironvale-fitness-club/

Members arrive, follow their own workout plans (sets, reps, load, rest), queue for equipment, walk between machines and floors, join instructor-led classes and run on the rooftop track. Click anyone to see their plan, then press **F** to follow them. Sound is off until you enable it in the panel; all music and effects are synthesized in the browser.

## About this file

- `index.html` is the standalone offline HTML file Claude produced, **unmodified**.

## How it was made

- One build prompt, plus one follow-up asking for the artifact link. No feature-change requests.
- Claude launched 10 sub-agents to build the modules in parallel.
- 3 h 4 m 32 s from the first request to the final response (wall-clock time, including waiting; not compute time).
